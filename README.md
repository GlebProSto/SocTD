# SocTD - Social Todo Network

Django-based social network for sharing todo posts with repost functionality.

## 🌟 Features

- User registration and authentication
- Create, edit, delete todo posts
- Repost other users' posts
- User profiles with avatars
- Feed with posts and reposts
