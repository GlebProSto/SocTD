# SocTD — Соцсеть для списков дел

Простая соцсеть на Django: тут можно публиковать посты-задачи, ставить лайки, комментировать, перепощивать чужие записи, дружить, общаться в личных сообщениях и вести списки своих задач с подзадачами.

## Что умеет

- Регистрация и вход
- Публикация постов-задач, лайки и комментарии к ним
- Репосты чужих записей
- Профиль с аватаркой, био и статистикой (подписки, подписчики, лайки, репосты, комментарии)
- Лента постов с постраничной навигацией
- Заявки в друзья, списки подписчиков и подписок
- Личные сообщения с счётчиком непрочитанных
- Уведомления: заявки в друзья, лайки, комментарии, репосты
- Свои списки задач с подзадачами и процентом выполнения
- Админка для управления данными

## Как запустить у себя на компьютере

Понадобится Python 3.13 (в проекте использовалась именно эта версия).

**1. Скачать проект и зайти в папку**
```bash
git clone https://github.com/GlebProSto/SocTD.git
cd SocTD
```

**2. Создать «виртуальное окружение»** (это изолированная песочница для пакетов проекта, чтобы не засорять системный Python):
```bash
python -m venv myenv
```
И включить его:
```bash
# Windows (в PowerShell):
myenv\Scripts\Activate.ps1

# Linux / macOS:
source myenv/bin/activate
```

**3. Установить нужные пакеты**
```bash
pip install -r requirements.txt
```

**4. Создать файл `.env`** прямо в папке проекта. В нём хранятся настройки и секреты (пароли), в git он не попадает:
```
SECRET_KEY=любая-длинная-строка-с-символами
DEBUG=True
DB_NAME=             # оставь пустым — будет работать на SQLite (проще всего)
DB_USER=postgres
DB_PASS=пароль-от-базы
DB_HOST=localhost
DB_PORT=5432
```

> **Проще всего оставить `DB_NAME` пустым** — тогда проект автоматически будет хранить данные в файле `db.sqlite3`, и ставить PostgreSQL не нужно. Если хотите работать с PostgreSQL — впишите имя базы и её данные.

**5. Подготовить базу данных** (создать таблицы):
```bash
python manage.py migrate
```

**6. (Необязательно) Создать администратора** для входа в админку:
```bash
python manage.py createsuperuser
```

**7. Запустить сайт**
```bash
python manage.py runserver
```

Готово. Открывайте в браузере:
- Сайт: http://127.0.0.1:8000/
- Админка: http://127.0.0.1:8000/admin/

Адрес `127.0.0.1` — это «этот же компьютер», с других устройств сайт по нему не откроется.

## Как проверить, что всё работает

Запустить встроенные тесты (они сами прогоняют все основные функции):
```bash
python manage.py test todo_app
```
Если в конце написано `OK` — всё в порядке.

Можно ещё быстро проверить, что нет явных ошибок в коде:
```bash
python manage.py check
```

## Из чего состоит проект

- `myproject/` — общие настройки Django (подключение базы, адреса, статика)
- `todo_app/` — само приложение: модели (данные), вьюхи (логика страниц), формы, шаблоны страниц, миграции (изменения структуры базы)
- `static/` — стили CSS, которые отвечают за внешний вид
- `media/` — загруженные аватарки пользователей (в git не хранятся)
- `.env` — файл с секретными настройками (в git не хранится)
- `requirements.txt` — список пакетов, которые нужно установить

## Несколько важных замечаний

- Проект предназначен для обучения и локального запуска. Для реального выхода в интернет настроек безопасности (DEBUG=False, домены, HTTPS, отдельный веб-сервер) пока нет.
- Секретный ключ и пароли держите в `.env` и не публикуйте их.
